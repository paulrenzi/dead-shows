## What to build, in order

### 1. Quick-filter chips (biggest UX win)

Above the existing strip controls (or replacing the From/To pickers as the default), add a row of single-tap chips:

- **Tonight** — today only
- **This Weekend** — today through next Sunday
- **Next 30 days** — today + 30 (default on load)
- **Within 25 mi** — radius shortcut (independent toggle, snaps the slider)
- **Dead family only** — show only artists with `tier: "core"` in `artists.json`

Behavior:
- Tapping a date chip updates `#start-date` + `#end-date` and re-runs `runSearch()`.
- Visual: pill row, sticky with the strip, active state in dead-blue. Chip selection is mutually exclusive within the date group; "Within 25mi" + "Dead family only" are additive toggles.
- Mobile: chips wrap to 2 rows naturally, no horizontal scroll.

Files: `index.html` (markup), `styles.css` (`.chip-row`, `.chip`, `.chip--active`), `app.js` (`wireChips()` function).

### 2. Add to Calendar + Share buttons per card

Inside `.card-foot`, add two small icon buttons next to "Show on map" and "Tickets":

- **📅 Add** — generates an `.ics` blob client-side and triggers download. Fields: SUMMARY=band name, DTSTART/DTEND from `ev.date` + parsed `ev.time` (default 7pm if absent, 3hr duration), LOCATION="venue, city, state", URL=`ev.url`, DESCRIPTION="via Dead Shows".
- **↗ Share** — `navigator.share({title, text, url})` on mobile; falls back to copying a deep-link to clipboard with a toast.

Helper in `app.js`: `buildIcs(ev)` returns a Blob, `shareEvent(ev)` does the navigator.share / clipboard dance.

Deep-link: `?event={id}` — `init()` reads it, scrolls to + highlights that card after first render. Optional but makes "Share" actually shareable.

Files: `app.js` (helpers + button wiring), `styles.css` (small icon-button styles).

### 3. Map ↔ card hover/tap sync

Wire bidirectional highlight between cards and map markers:

- Hovering a `.event-card` → corresponding marker bounces / opens popup briefly (Leaflet's `L.divIcon` with a `.marker--active` class, or just `marker.openPopup()` on hover and close on leave).
- Clicking a marker → scroll its card into view + add `.event-card--active` class (subtle outline).
- Already have `markerById` map keyed by `ev.id`; build the inverse `cardByEventId` on render.

Files: `app.js` (`renderEvents()` — add hover/click handlers), `styles.css` (`.event-card--active`, `.marker--active`).
